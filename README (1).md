# Bac Bo Signal Pro

Projeto Android baseado em Capacitor.

## Estrutura

- `www/` — interface do aplicativo
- `capacitor.config.json` — configuração do Capacitor
- `package.json` — dependências
- `codemagic.yaml` — configuração para gerar APK automaticamente

## Build

O Codemagic instala as dependências, cria o projeto Android, sincroniza os arquivos e gera:

`android/app/build/outputs/apk/debug/app-debug.apk`

## Nota

O aplicativo fornece análise estatística e não garante resultados em jogos de casino.
